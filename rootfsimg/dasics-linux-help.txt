FDI Linux validation

The unified suite contains 14 programs with 27 invocations. Run /dasics/suite
for the user suite, /dasics/kernel-runner for the three kernel suites, or
/dasics/run-all for both. Kernel suites require their six modules in /modules.
The startup script loads the trusted fdi_verify observer before these tests.

Programs and coverage:
  dasics-test-validation-smoke             observer ABI and privilege controls
  dasics-test-csr-unified                  user CSR banks, masks and operations
  dasics-test-fdicall-unified              direct/indirect call encoding and ReturnPC
  dasics-test-control-flow-unified         jump permissions and trusted destinations
  dasics-test-memory-isa                   access widths, bounds, permissions and slots
  dasics-test-memory-library               library-managed memory permissions
  dasics-test-dynamic-unified              allocation, replacement and permission removal
  dasics-test-ecall-unified                user ECALL isolation and controlled service
  dasics-test-maincfg-toggle-smoke         MainCfg controls and restore
  dasics-test-context-switch-isolation-smoke  fork, exec and context isolation
  dasics-test-lifecycle                    exit followed by exec state isolation
  dasics-test-utimer                       user timer and context isolation
  dasics-test-amo-permission-smoke          LR, SC and AMO permissions
  dasics-test-cbo-permission-smoke          cache-block operation permissions

Single-case examples:
  /dasics/dasics-test-csr-unified -dasics
  /dasics/dasics-test-memory-isa --width=64 --scenario=matrix -dasics
  /dasics/dasics-test-utimer --expect=on --isa-extended -dasics
  /dasics/kernel-runner fault-recovery --rounds=2

The kernel runner refuses occupied modules and unloads only its own modules.
Exit status and emitted assertions describe the current invocation.
